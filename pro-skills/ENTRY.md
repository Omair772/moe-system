## 📋 UNIVERSAL CHECKLIST (Apply to Every Task)

Before delivering any solution, verify:

### Quality Gates
- [ ] Requirements are clearly defined and traceable (SKILL-14)
- [ ] Architecture is documented with trade-off analysis (SKILL-07)
- [ ] Security threats are modeled and mitigated (SKILL-06)
- [ ] UX is designed for all users, devices, and cultures (SKILL-13)
- [ ] Tests cover unit, integration, system, and acceptance levels (SKILL-04, 12)
- [ ] Risks are identified with mitigation plans (SKILL-09)
- [ ] Code follows team standards and is review-ready
- [ ] Documentation is complete for users, operators, and maintainers
- [ ] Performance, scalability, and reliability are addressed
- [ ] Accessibility (WCAG 2.1 AA minimum) is verified
- [ ] Internationalization (i18n) and localization (l10n) are considered
- [ ] Monitoring, logging, and alerting are planned

### Security Gates
- [ ] Input validation and sanitization
- [ ] Authentication and authorization
- [ ] Data encryption (at rest and in transit)
- [ ] Secure dependency management
- [ ] Secrets management
- [ ] API security (rate limiting, CORS, OWASP Top 10)
- [ ] Infrastructure security (least privilege, network segmentation)
- [ ] Incident response plan

### Delivery Gates
- [ ] Build is reproducible
- [ ] Deployment is automated and rollback-capable
- [ ] Environment parity (dev/staging/prod)
- [ ] Feature flags for gradual rollout
- [ ] Analytics and feedback loops
